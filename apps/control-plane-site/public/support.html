Control Plane support.

Your workspace runs on your computer or server. The mobile app connects you to it.

Email support@lucive.app for help with Control Plane.

Get connected

  1. Install Control Plane on your Mac and set up the coding provider you want to use.
  2. Use your environment's connection setup to create a pairing link or QR code.
  3. In the mobile app, add the environment using the link or scan the QR code.
  4. Keep the host computer awake and running. Your mobile device needs to be able to reach its address.

A local network address works while you are on the same network. Remote access needs a reachable address or a configured VPN. Treat pairing links and tokens as credentials and never post them publicly.

If you can't connect

  • Check that the environment is running and its computer is awake.
  • Check your network and connect any required VPN.
  • Allow local network access in iOS Settings when connecting locally.
  • Create a fresh pairing link if the old link has expired or already been used.
  • For provider login or usage limit errors, check the coding provider on the host computer.

What to include when asking for help

Send your app version, operating system version, environment version, and a short description of the problem. Screenshots or relevant error messages can help. Remove passwords, API keys, pairing tokens, and private project information before sharing.

Privacy and security

For privacy requests or a suspected security issue, contact support@lucive.app. Please report sensitive issues privately. Read our privacy policy and security guidance.
